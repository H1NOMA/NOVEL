# Роадмап до релиза в Steam

Этапы упорядочены так, чтобы каждый заканчивался работающей игрой. P0 сделан,
дальше — по порядку; внутри этапа порядок задач свободный.

## P0 — Прототип архитектуры ✅ (этот коммит)

- [x] Ядро: интерпретатор, переменные, условия, ветвления, концовки
- [x] Движко-независимый формат сценария + статический валидатор
- [x] Web-раннер: титул, текстбокс, выборы, история, сейвы (3 слота + автосейв)
- [x] Демо-сценарий, прогоняющий все механики
- [x] Тесты ядра (25), typecheck, production-сборка, CI

## P1 — Играбельность и контент-пайплайн (1–2 недели)

Цель: писать сценарий удобно, играть приятно.

- [ ] **Определиться с сеттингом** — блокирует арт и текст, не блокирует код
- [ ] Печатающийся текст (typewriter) + клик = показать сразу; скорость в настройках
- [ ] Режимы Skip (прочитанного — поле `seen` уже копится) и Auto
- [ ] Экран настроек: скорость текста, громкости (заготовка), язык (заготовка)
- [ ] Переезд сценария из TS в `.json`/`.yaml` файлы + загрузка глав чанками
- [ ] Хоткеи: Ctrl — skip, H — спрятать UI, колесо мыши — история
- [ ] Транзишены фонов/спрайтов (fade/dissolve) — CSS, дёшево
- [ ] Прогон валидатора отдельной командой `npm run lint:scenario`

## P2 — Медиа (2–3 недели, параллельно с написанием сценария)

- [ ] Реальные ассеты: фоны, спрайты с эмоциями (`show` с `id: "guide_smile"`),
      CG-иллюстрации; манифест ассетов → пути к файлам, предзагрузка сцены
- [ ] Аудио: музыка (кроссфейд), sfx, громкости по каналам (WebAudio)
- [ ] Галерея CG и концовок (открывается по мере прохождения — глобальный
      "persistent"-стор рядом с сейвами)
- [ ] Разрешения/фулскрин, letterboxing 16:9

## P3 — Десктоп и Steam-инфраструктура (2 недели)

- [ ] Оболочка **Tauri v2** (запасной вариант — Electron): webview поверх `dist/`
- [ ] Сейвы в файлы (`%APPDATA%/…`), экспорт/импорт; миграции сейвов по
      `scenarioVersion`
- [ ] Регистрация приложения в Steamworks ($100), настройка депо
- [ ] steamworks.js: инициализация, достижения, Steam Cloud на папку сейвов,
      оверлей
- [ ] CI-сборки Windows + Linux (Steam Deck!) + macOS; загрузка через SteamPipe
- [ ] Проверка на Steam Deck (управление, читаемость шрифта, Proton не нужен —
      нативный Linux-билд)

## P4 — Контент-финал (зависит от объёма сценария)

- [ ] Полный сценарий, вычитка, консистентность веток (валидатор + скрипт
      обхода всех путей — «какие концовки достижимы»)
- [ ] Локализация: тексты сценария уже данные → выгрузка в таблицы,
      второй язык (минимум EN — в Steam без EN плохо с видимостью)
- [ ] Плейтесты, аналитика веток (какие выборы никто не делает)

## P5 — Релиз (последние 4–6 недель)

- [ ] Страница в Steam минимум за месяц до релиза: капсулы, скриншоты, трейлер,
      теги (Visual Novel, Choices Matter, …), вишлисты
- [ ] Демо в Steam (наш web-билд = бесплатное демо на itch.io для трафика)
- [ ] Steam Next Fest с демо — главный источник вишлистов
- [ ] Ценообразование, региональные цены, ревью билда Valve (~1–5 дней)
- [ ] Пресс-кит, ключи блогерам VN-ниши, день релиза

## Технический долг, за которым следим

- `sfx` пока no-op в раннере (шаг есть, звука нет) — закрывается в P2
- История ограничена 300 записями; сейв растёт с историей — при больших главах
  вынести историю из сейва
- Один сценарий = один файл — дробление на главы в P1
