# Формат сценария

Сценарий — сериализуемая структура (JSON-совместимая). Сейчас демо лежит в
`src/scenario/demo.ts` как типизированный TS-объект (бесплатная проверка типов
редактором), но тот же объект можно хранить в `.json` и грузить с диска —
ядру всё равно. Типы: `src/engine/types.ts`.

## Каркас

```jsonc
{
  "meta": {
    "id": "my-novel",        // уникальный id — им помечаются сейвы
    "title": "Название",
    "version": 1,            // поднимать при несовместимых изменениях
    "start": "intro",        // стартовая сцена
    "vars": { "trust": 0 }   // начальные переменные
  },
  "characters": {
    "guide": { "name": "Проводница", "color": "#7ec8e3" }
  },
  "scenes": {
    "intro": { "steps": [ /* шаги */ ] }
  }
}
```

## Шаги

| Шаг | Пример | Что делает |
|---|---|---|
| `say` | `{ "type": "say", "who": "guide", "text": "Привет, {player}." }` | Реплика. Без `who` — авторский текст. `{var}` интерполируется. **Блокирующий.** |
| `bg` | `{ "type": "bg", "id": "polygon" }` | Сменить фон (id из манифеста ассетов) |
| `show` | `{ "type": "show", "slot": "left", "id": "guide" }` | Показать спрайт в слоте `left/center/right` (по умолчанию `center`) |
| `hide` | `{ "type": "hide", "slot": "center" }` | Убрать спрайт |
| `music` | `{ "type": "music", "id": "ambient" }` | Сменить музыку (`null` — тишина) |
| `sfx` | `{ "type": "sfx", "id": "door" }` | Одноразовый звук |
| `set` | `{ "type": "set", "ops": [{ "var": "trust", "op": "add", "value": 1 }] }` | Изменить переменные |
| `branch` | `{ "type": "branch", "cond": {...}, "then": "sceneA", "else": "sceneB" }` | Условный переход. Без `else` при ложном условии — следующий шаг |
| `choice` | см. ниже | Выбор игрока. **Блокирующий.** |
| `jump` | `{ "type": "jump", "to": "hub" }` | Безусловный переход в сцену |
| `end` | `{ "type": "end", "ending": "good" }` | Концовка. **Блокирующий.** |

Правило: **последний шаг сцены обязан уводить из неё** (`jump`, `end`, `choice`
или `branch` с `else`) — иначе валидатор ругается ошибкой.

## Выбор

```jsonc
{
  "type": "choice",
  "prompt": "Что делать?",                       // опционально
  "options": [
    { "text": "Открыть дверь", "goto": "door",
      "cond": { "var": "has_key" } },            // вариант виден только с ключом
    { "text": "Довериться", "goto": "trust_path",
      "set": [{ "var": "trust", "op": "add", "value": 1 }] }
  ]
}
```

## Условия

Дерево без eval: лист — проверка одной переменной, узлы — `all`/`any`/`not`.

```jsonc
{ "var": "trust", "gte": 2 }                    // trust >= 2
{ "var": "has_key" }                            // truthy
{ "not": { "var": "has_key" } }
{ "all": [ { "var": "trust", "gte": 2 }, { "var": "route", "eq": "guide" } ] }
```

Операторы листа: `eq`, `ne`, `gt`, `gte`, `lt`, `lte` (числовые сравнения с
нечисловым значением — `false`, не ошибка).

## Операции над переменными

```jsonc
{ "var": "gold", "op": "set", "value": 10 }   // op по умолчанию — set
{ "var": "gold", "op": "add", "value": -3 }   // add к отсутствующей — от 0
{ "var": "lights", "op": "toggle" }
```

## Соглашения

- id сцен — `snake_case`, по смыслу: `ch1_cafe_meet`, `ending_good`.
- Переменные: флаги — `has_*` / `met_*`, счётчики отношений — по имени
  персонажа (`trust_guide`), маршрут — `route`.
- Одна сцена ≈ одна «единица монтажа» (место + отрезок диалога). Длинные
  диалоги дробить сценами — так проще ссылаться и мержить.
- После любого изменения сценария: `npm test` — валидатор входит в тесты.
