## 1. Что это за проект

Полноценная настольная RTS во вселенной **Helldivers 2**: «Вторая Галактическая
война». Игрок ведёт одну из фракций (по умолчанию Супер-Землю) в десятилетней
войне за процедурную галактику из ~200 объёмных планет.

- **Стек:** Vite + TypeScript + Three.js, десктоп-обёртка Electron. Без бэкенда и
  внешних ассетов — планеты рисуются GLSL-шейдером процедурно.
- **Язык:** весь интерфейс, тексты, логи, коммиты и общение с пользователем — **по-русски**.
- Разработка идёт итеративными «раундами»: пользователь даёт список правок →
  реализация → проверка → коммит → **релиз через CI** → отчёт со ссылками.

## 2. Жёсткие правила от пользователя (не нарушать)

1. **Каноничные иконки/ассеты HD2 не копировать 1:1** — только собственные
   процедурные стилизации (эмблемы, иконки фокусов, портреты — всё рисуется кодом).
2. **ЛКМ по планете — только информация.** Приказы (перелёт/вторжение) — **ПКМ**
   выбранным флотом. Shift+ЛКМ по кнопке «выбрать» — мультивыбор флотов, потом ПКМ по цели.
3. Карта двигается **WASD**, правая кнопка — поворот камеры, ЛКМ-рамка — выделение планет.
4. Карточки соединений — по центру нижней кромки (как в HoI4). Панель производства —
   отдельно от политических решений.
5. Дизайн — спокойный, единый стиль, без «вырвиглазности».
6. Мини-карту пользователь **отклонил** («Давай всё, кроме мини-карты») — не добавлять.
7. Идентификатор модели не должен попадать в коммиты/PR/код.
8. Коммиты по-русски, с трейлером:
   ```
   Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
   ```

```
  render/  scene.ts (GalaxyScene: камера, секторы, стрелки атак, пульсы захвата,
```

Отладочный крючок для тестов и консоли: `window.__game = { state, scene, clock, ui }`.

## 5. Ключевые механики (сводка по раундам)

- **Экономика связана:** производство + ископаемые → корабли/войска; содержание флота;
  людские резервы конечны; станция Е-711, шахтные города.
- **Верфи:** корабли игрока строятся только на верфях по его приказу; склад корпусов,
  забор флотом на орбите, формирование нового соединения; тумблер «🔁 повтор».
- **Туман войны:** чужие флоты видны только при вторжении или у своих планет.
  Линии атаки врага по своим планетам видны (стрелки-эскалатор цвета фракции).
- **Снабжение атаки:** флот снабжается с планеты, с которой атаковал (Fleet.origin).
  Окружённые планеты — осада: гарнизон и контроль тают, мир меркнет (uDim).
- **ИИ:** кампанийные планы (updatePlan), автоматоны при чертежах супероружия целятся
  в магмовый мир с рудой и строят особый док; терминиды прут к Супер-Земле;
  коалиция против гегемона (>38% живых планет → +2.5 к приоритету его миров).
- **Капитуляция роя:** только когда осталось 1–2 улья в главном секторе (Кеплер Прайм);
  планеты-марионетки (puppetOf) — жучьи визуально, без сопротивления.
- **Проект «Ковчег»:** автоматоны без планет → фокус на 30 дней → из тьмы со стороны
  Супер-Земли прилетает Ковчег (флагман-супероружие), захватывает плацдарм.
- **Супер-Федерация:** гражданская война СЗ, переприсяга миров, Новый Конкорд.
- **Таймлайн:** 35 ивентов на 10 лет (по датам и по захвату миров), 4 — с выбором
  игрока (пауза + кнопки на баннере; ИИ берёт первый вариант; баннер развилки
  не перекрывается другими ивентами).
- **Дипломатия:** перемирие за 120 ПВ на 90 дней (diplomacy.ts: buyTruce/hostileNow/stepTruces).
- **Командиры:** 13 офицеров, один на флот, бонусы к бою/захвату, кнопка ★ в карточке
  соединения, переживают сейв.
- **Города:** spec 'yard' (−25% срока стапеля) / 'academy' (×1.35 рост гарнизона) /
  'mine' (+0.06 руды/день).
- **Цели кампании:** 6 штук (objectives.ts), ежедневная проверка, награды ПВ, список в досье.
- **Визуал:** ACES-тонмаппинг, bloom (UnrealBloomPass 0.35/0.55/0.85), виньетка (#vignette),
  пожары на сражающихся планетах (uBattle), пульс-кольцо при смене владельца,
  цветные туманности у клиньев фракций (золото ~0°, багрянец ~135°, фиолет ~257°),
  кометы, карта Земли на Супер-Земле (CanvasTexture-маска), стили суши
  (архипелаг/материки/пангея), хребты пустынь, кратеры, лавовые океаны.

## 6. Как тестировать (рецепты сессии)

**Юнит-тесты** лежали в scratchpad сессии (в репо их нет) — в новом чате пересоздать
по необходимости. Рецепт сборки:
```bash
# тест импортирует модули АБСОЛЮТНЫМИ путями: from '/home/user/NOVEL/src/game/state'
npx --prefix /home/user/NOVEL esbuild T.ts --bundle --platform=node --format=cjs --outfile=T.mjs
node T.mjs
```
Сьюты, которые гонялись перед каждым релизом: longrun (3 сида × 300 дней, инварианты),
defeat-test, ark-test, round20-test (экономика/планы ИИ), ops-test (осады/плацдармы),
yard-test (верфи), round28-test (дипломатия/командиры/цели/развилки).

**Браузерный смоук** (playwright ставится временно, перед коммитом — `npm remove playwright`):
```bash
npm i -D playwright && npx vite build && npx vite preview --port 4173 &
# chromium.launch({ executablePath: '/opt/pw-browsers/chromium', args: ['--use-angle=swiftshader','--no-sandbox'] })
```

**Грабли (проверено на собственной шкуре):**
- `advanceDay` **не двигает флоты** — в тестах вызывать `moveFleets(state, 1)` на каждый день
  (в игре это делает GameClock.frame).
- В headless rAF ~2 кадра/с: дни и рендер двигать вручную —
  `g.clock.dayFloat = g.state.day; g.state.speed = 3; g.clock.frame(0.5)` в цикле;
  кадры — `g.scene.render()` в evaluate.
- UI перерисовывает DOM — хэндлы элементов протухают, пере-запрашивать `page.$` после кликов.
- Кнопки могут быть disabled на момент отрисовки (например, перемирие без ПВ) —
  выставлять состояние **до** открытия панели.
- `pkill` возвращает 144 и рубит `&&`-цепочку — запускать отдельной командой.
- `tsc`/`vite` запускать только из `/home/user/NOVEL` (иначе tsc печатает help).
- **Детерминизм генерации:** никакого модульного мутабельного состояния в galaxy/names
  (баг usedSectors ловили долго). Любой новый RNG-вызов в генерации сдвигает карты
  всех сидов — тесты, привязанные к конкретным планетам сида, надо ослаблять
  (проверять свойства, а не id).
- `state.fleets` — это `Map`, в evaluate использовать `[...g.state.fleets.values()]`.
- Приватные поля UI доступны в рантайме: `g.ui.detailFleet = id; g.ui.renderFleetDetail()`.
