# NOVEL — прототип визуальной новеллы

Архитектурный прототип VN с прицелом на релиз в Steam: движко-независимый
формат сценария, чистое ядро-интерпретатор и web-раннер. Сеттинг не определён —
демо-контент нейтральный и заменяется целиком без изменений кода.

## Запуск

```bash
npm install
npm run dev        # дев-сервер: http://localhost:5173
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с hot reload |
| `npm run build` | Production-сборка в `dist/` (статика, работает откуда угодно) |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm test` | Тесты ядра + валидация сценария |
| `npm run typecheck` | Проверка типов |

## Что уже умеет

- Реплики, авторский текст, интерполяция переменных `{var}`
- Выборы, в т.ч. с условиями видимости и эффектами на переменные
- Переменные (числа/строки/булевы), условия без eval, ветвления, концовки
- Фоны/спрайты/музыка как id-плейсхолдеры (арт подключается манифестом)
- Сейвы: 3 слота + автосейв, восстановление экрана целиком; бэклог истории
- Статический валидатор сценария (битые ссылки, незавершённые сцены)

## Структура

```
src/engine/     ядро: интерпретатор, условия, сейвы, валидатор (без DOM)
src/ui/         web-раннер: рендер, экраны, localStorage-сейвы
src/scenario/   сценарий (данные)
tests/          тесты ядра
docs/           ARCHITECTURE.md · SCENARIO_FORMAT.md · ROADMAP.md
```
